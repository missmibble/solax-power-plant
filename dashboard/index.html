    Grid Discharge Control

    Setting What it does Value
    When off, the 5-9pm feed-in discharge is skipped entirely — start, check, and exit all leave the battery on its normal Self Use schedule instead.
    Dry run only logs and emails what each phase (start/check/exit) would do, without ever calling the inverter. Live enables actually discharge to the grid. Dry run

    If the evening feed-in discharge (5-9pm) is running and you want to stop it early — e.g. before an expected spike in household demand — this returns the inverter to its normal schedule immediately. Safe to press even if nothing is currently running.
